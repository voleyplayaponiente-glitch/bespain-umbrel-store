# BESPAIN — Tienda personal de apps de Umbrel

Community app store de Umbrel con **Gestor Laboral** (cuadrantes y control de
horas del personal). Para usarla, en Umbrel: **App Store → ⋯ → Community App
Stores → Add** y pegar la URL de este repositorio.

La imagen de la app se construye automáticamente desde
[clauderoutine](https://github.com/voleyplayaponiente-glitch/clauderoutine)
(rama `claude/labor-management-scheduling-app-jd2hcj`) y se publica en
`ghcr.io/voleyplayaponiente-glitch/gestor-laboral`.
